# Sheets Lab

A 5-day hands-on Google Sheets course with a live practice workbook in the browser. Each lesson has exercises that check your formulas against made-up webinar data, plus tasks to do in real Google Sheets.

Open it: https://nk-v1.github.io/sheets-lab/

All data in the page is made up. Formulas run on [HyperFormula](https://hyperformula.handsontable.com/) (GPL-3.0).
